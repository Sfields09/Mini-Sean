# Mini Sean 

Mini Sean is a Windows desktop companion designed to bring some fun and character to your computer. With voice recordings, visual effects, and interactive features, Mini Sean adds a little personality to your desktop experience.

## Features

-  **Voice recordings** — Hear Mini Sean's prerecorded voice lines.
-  **Dance breaks** — Enjoy dance animations and images.
-  **Idle interactions** — Mini Sean can play voice lines during idle moments.
-  **Welcome-back interactions** — Includes a welcome-back voice feature.
-  **Closing interactions** — Includes a voice feature for when the window closes.
-  **Desktop application** — Run Mini Sean as a standalone Windows app without opening Python or PyCharm.
-  **Custom shortcut icon** — Install Mini Sean with its own desktop shortcut icon.

## Download and Install

1. Visit the **Releases** section of this GitHub repository.
2. Download `MiniSean-Setup.exe` from the latest release.
3. Open the downloaded installer.
4. Follow the installation instructions.
5. Launch Mini Sean from the desktop shortcut.

**You do not need to install Python or PyCharm** to use the packaged Windows release.

> **Windows note:** Windows may display a security warning because the application is not signed with a recognized code-signing certificate. Only run software you trust and that you downloaded from the official project release.
